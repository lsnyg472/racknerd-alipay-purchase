## 第一步：注册账号

进入 RackNerd 官网，右上角点 **MY ACCOUNT** 进入登录页，再点 **Register** 就到注册界面。真正必填的核心信息只有两样：邮箱和密码。邮箱务必用真实常用邮箱——开通邮件、续费通知、工单回复全发这里，填错了服务器信息就收不到了。

其余资料建议照实填。RackNerd 的服务条款要求注册人年满 18 岁，且有针对欺诈性付款的风控条款：欺诈订单会被立即暂停或终止，数据直接删除。有一条第三方教程反复强调的实操建议值得记住——**用本地网络直连下单**，如果下单 IP 和账单地址所在地区对不上，可能触发订单欺诈审核，卡在开通环节。

## 第三步：收开通邮件，进 ctrl 面板

RackNerd 的 KVM VPS 是付款后自动开通的，官方说法是“付款后立即交付，几分钟内即可上线”。开通邮件里包含 VPS 的 IP 地址、root 密码和管理面板入口。官方条款写明：30 分钟内没收到邮件，先查垃圾箱，再联系客服。

拿到 IP 和密码后，SSH 连上去（`ssh root@你的IP`）就能开始用了。日常管理在 RackNerd 自研的 ctrl 面板里完成，功能包括：

- 重启、关机、重装系统（可随时换发行版）
- HTML5 VNC 控制台，SSH 连不上时的兜底手段
- 一键应用：n8n、Coolify、Ollama、AnythingLLM、LibreChat 等，选好应用后凭据直接显示在面板里

## 这几条限制只写在条款里，下单前看一眼

服务条款里有几条对使用决策影响不小，但很少出现在测评文章里：

- **默认非托管**：RackNerd 的 VPS 默认是 unmanaged 服务，也就是说服务器环境配置、软件安装、故障排查都得自己动手，官方提供 7×24 客服但没有代管服务。完全没有 Linux 基础的话，买之前要想清楚这一点。
- **不含备份**：默认不带托管备份，官方明确声明不对数据完整性负责，建议自行做异地备份。数据重要的用途自己配定时备份任务。
- **禁止嵌套虚拟化**：在 KVM VPS 里再开虚拟机、转卖 VPS、跑需要硬件虚拟化的模拟器，未经书面批准不允许，官方也不保证暴露 VT-x/AMD-V 标志。Docker、LXC/LXD、Kubernetes 等容器方案不受此限制。
- **禁止的活动**：CPU 加密货币挖矿、垃圾邮件、暴力破解、外发 DDoS、Traffic Exchange 都在禁止之列，违规会面临警告、暂停或终止服务。
- **付款争议有额外费用**：对已因违规被处罚的服务发起付款争议（拒付），会被收取 $125–250 的管理费。
- **资源公平使用**：磁盘 I/O 和 CPU 不能长期满载滥用，需要独占资源持续跑满的场景官方建议直接上独立服务器。

## 续费、退款和几个常见问题

**续费会涨价吗？** 官方特价页明确标注这些套餐是 lifetime recurring（终身循环价），续费价格和首购一致。$21.99 买的 1 GB 套餐，第二年、第三年续费还是 $21.99。中文圈把它叫“传家宝 VPS”就是这个原因——几年前买的几美元年付套餐，到现在续费还是原价。这也是算总成本时最省心的一类：第一年多少钱，之后每年就多少钱。

**能退款吗？** RackNerd 官方条款里没有公开的无理由退款承诺，这一点和某些提供试用期的大厂不同。付款争议的处理在上面条款部分已经说过：对被处罚服务发起争议要付 $125–250 管理费。所以下单前把机房、配置确认好，比买完再反悔靠谱得多。

**需要优惠码吗？** VPS 不需要。特价套餐价格直接生效，任何声称能让 VPS 再打折的码都别当真。

**适合谁，不适合谁？** 预算敏感、想要年付锁价、有基本 Linux 操作能力的个人用户，RackNerd 的特价套餐在这个价位段配置给得扎实（KVM 架构、RAID-10 SSD、独立 IPv4）。需要托管服务、官方备份保障或者企业级 SLA 的，这个价位段都给不了，得往更贵的托管方案看；需要 CN2 GIA 这类高端回国线路的，也不该拿它和线路型高端 VPS 比。
